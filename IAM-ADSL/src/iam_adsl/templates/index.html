Semi-Auto Étude. Si le Quartier ou la Voie est inconnu, la recherche Excel reste disponible et vous choisissez manuellement la Constitution à appliquer.
Bulk Auto Etude. Collez les CMD manuellement ou importez un PDF. Le PDF conserve uniquement les CMD Cuivre dégroupage ADSL et Cuivre IAM ADSL dont l'état est EI, IR ou EE. Les lignes FO sont ignorées.
Ré-Étude VA. Recherche le CMD dans Mutation, récupère son adresse, trouve automatiquement une Constitution dans la base Excel, supprime l'ancienne constitution puis cherche dans tous les chemins transport par priorité MSAN → TT → TTR : d'abord PAIRE-Libre, puis PAIRE-En cours decon si aucune paire libre n'existe.
0 = aucun délai. Exemple : 1.5 = 1,5 seconde entre les étapes.
Bulk Ré-Étude VA. Collez un CMD par ligne. Chaque CMD est traité séquentiellement avec le même workflow que Ré-Étude VA, y compris la détection SR normal / zone radian.
0 = aucun délai.
Recherche Adresse. Recherche directe dans la base Excel, sans CMD et sans Selenium. Vous pouvez saisir une partie du SR/Répartiteur et/ou une partie de l'adresse.
